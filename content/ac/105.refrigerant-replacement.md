## Удаление хладагента:

1. Включите кондиционер и дайте поработать системе в следующих условиях:

| Контакты              | Состояние           |
| :-------------------- | :------------------ |
| Время работы          | 3 минуты или дольше |
| Температура           | Lo (минимальная)    |
| Скорость вентилятора  | ∗7 (максимальная)   |

В результате большая часть компрессорного масла из различных компонентов системы кондиционирования скапливается в самом компрессоре кондиционера.

{{< callout >}}
Если кондиционер не работает из-за неисправности компрессора, нет необходимости запускать компрессор.
{{< /callout >}}

2. Выключите кондиционер.
3. С помощью специализированного оборудования удалите хладагент из системы.

## Добавление хладагента:

1. Выполните вакуумизацию системы кондиционирования с помощью специализированного оборудования.
2. Наблюдайте за давлением в течение 5 минут, давление не должно падать.
3. Добавьте хладагент в систему кондиционирования:
  - тип хладагента: R134a
  - дозировка: UNEC, UNED: 1250±10 г

{{< callout type="important" >}} 
Не включайте кондиционер до заправки системы хладагентом, при работе без хладагента компрессор может выйти из строя.
{{< /callout >}}
