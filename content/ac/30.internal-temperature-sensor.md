### Проверьте датчик температуры салона

Отсоедините разъем G05 переднего датчика температуры салона и снимите датчик. 

![Разъем G05](/images/conn_g05.png)

Измерьте сопротивление согласно таблице ниже:

| Контакты      | Температура во время измерения | Нижний предел (kΩ) | Верхний предел (kΩ) |
| :-----------: | :----------------------------: | :----------------: | :-----------------: |
| G05.1 - G05.2 | -25 °C                         | 126.4              | 134.7               |
|               | -10 °C                         | 54.60              | 57.65               |
|               | 0 °C                           | 32.25              | 33.69               |
|               | 10 °C                          | 19.68              | 20.35               |
|               | 20 °C                          | 12.37              | 12.67               |
|               | 30 °C                          | 7.95               | 8.14                |
|               | 50 °C                          | 3.51               | 3.66                |

> При обнаружении неисправности замените датчик

### Осмотрите жгут проводов

Отсоедините разъем G05 переднего датчика температуры салона и многофункциональный разъем G64(K), проверьте сопротивление между клеммами:

| Контакты       | Цвет линии | Норма     |
| :------------: | :--------: | :-------: |
| G64K.1 - G05.2 | W          | менее 1 Ω |
| G05.2 - кузов  | B          | менее 1 Ω |

> При обнаружении неисправности замените жгут проводов

## Снятие и установка

Датчик температуры салона расположен в нижней левой части приборной панели, над левым коленом водителя.

Инструменты: крестовая отвертка.

Снятие:

1. Выключите автомобиль.
2. Отсоедините отрицательную клемму аккумулятора.
3. Снимите нижнюю левую декоративную панель приборной панели.
4. Снимите датчик температуры салона автомобиля:
  - отсоедините разъем с датчика температуры.
  - с помощью короткой крестовой отвертки открутите крепежный винт датчика;
  - снимите датчик.

![Датчик температуры салона](/images/ac_inernal_temperature_sensor_assembly.png)

Установка:

1. Установите и закрепите датчик температуры салона автомобиля;
2. Подключите разъем датчика.
3. Установите нижнюю левую декоративную панель приборной панели.
4. Подсоедините отрицательную клемму аккумулятора.
