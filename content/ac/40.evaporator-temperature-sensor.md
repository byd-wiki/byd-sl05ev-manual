## Проверьте датчик температуры испарителя

Отсоедините разъем G22. 

![Разъем G22](/images/conn_g22.png)

Измерьте сопротивление согласно таблице ниже:

| Контакты        | Температура во время измерения | Нижний предел (kΩ) | Верхний предел (kΩ) |
| :-------------: | :----------------------------: | :----------------: | :-----------------: |
| G22.12 - G22.11 | -20 °C                         | 14.82              | 16.38               |
|                 | 0 °C                           | 5.081              | 5.559               |
|                 | 10 °C                          | 3.101              | 3.359               |
|                 | 15 °C                          | 2.466              | 2.644               |
|                 | 20 °C                          | 1.946              | 2.106               |
|                 | 30 °C                          | 1.276              | 1.354               |
|                 | 40 °C                          | 0.845              | 0.897               |

> При обнаружении неисправности замените датчик

## Осмотрите жгут проводов

Отсоедините разъем G22 датчика температуры испарителя и многофункциональный разъем G64(K), проверьте сопротивление между клеммами:

| Контакты         | Цвет линии | Норма     |
| :--------------: | :--------: | :-------: |
| G64K.23 - G22.12 | R          | менее 1 Ω |
| G22.11 - кузов   | B          | менее 1 Ω |

> При обнаружении неисправности замените жгут проводов
