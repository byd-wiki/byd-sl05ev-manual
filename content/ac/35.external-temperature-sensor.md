### Проверьте датчик наружной температуры

Отсоедините разъем B12 датчика наружной температуры и снимите датчик. 

![Разъем B12](/images/conn_b12.png)

Измерьте сопротивление согласно таблице ниже:

| Контакты      | Температура во время измерения | Нижний предел (kΩ) | Верхний предел (kΩ) |
| :-----------: | :----------------------------: | :----------------: | :-----------------: |
| B12.1 - B12.2 | -25 °C                         | 126.4              | 134.7               |
|               | -10 °C                         | 54.60              | 57.65               |
|               | 0 °C                           | 32.25              | 33.69               |
|               | 10 °C                          | 19.68              | 20.35               |
|               | 20 °C                          | 12.37              | 12.67               |
|               | 30 °C                          | 7.95               | 8.14                |
|               | 50 °C                          | 3.51               | 3.66                |

> При обнаружении неисправности замените датчик

### Осмотрите жгут проводов

Отсоедините разъем B12 датчика наружной температуры и многофункциональный разъем BG64(C), проверьте сопротивление между клеммами:

| Контакты         | Цвет линии | Норма     |
| :--------------: | :--------: | :-------: |
| BG64C.20 - B12.2 | Sb         | менее 1 Ω |
| B12.1 - кузов    | B          | менее 1 Ω |

> При обнаружении неисправности замените жгут проводов

## Снятие и установка датчика наружной температуры

Датчик наружной температуры расположен за передним бампером.

Инструменты: плоская отвертка.

Снятие:

1. Выключите автомобиль.
2. Отсоедините отрицательную клемму аккумулятора.
3. Снимите передний бампер.
4. Снимите датчик наружной температуры:
 - отсоедините разъем;
 - с помощью плоской отвертки снимите датчик со стенки воздуховода.

![Датчик наружной температуры](/images/ac_external_temperature_sensor_assembly.jpg)

Установка:

1. Установите датчик наружной температуры:
  - установите датчик на стенку воздуховода;
  - подключите разъем.
2. Установите передний бампер.
3. Подсоедините отрицательную клемму аккумулятора.
